# AP Microeconomics

### → **[sevketgunduz.github.io/ap-microeconomics](https://sevketgunduz.github.io/ap-microeconomics/)**

Course materials for AP Microeconomics, built on *Krugman's Economics for AP* and aligned
to the College Board Course and Exam Description (Course Framework V.1, © 2022).

Teaching notes for the teacher, a study guide and a test for the student, and one gap
analysis per unit — across all six units of the course. The site shows the whole course
map from the start, so what is written and what is still to come are both visible.

**Start with the [course specification](https://sevketgunduz.github.io/ap-microeconomics/spec.html)**
for the six units, the 36 topics and how the documents are structured, or go straight to
[Module 1 — The Study of Economics](https://sevketgunduz.github.io/ap-microeconomics/m01-student.html)
and [Module 3 — The Production Possibilities Curve Model](https://sevketgunduz.github.io/ap-microeconomics/m03-student.html),
which includes an interactive PPC explorer.

Modules 1 and 3 of Krugman are shared with the macroeconomics course, but their *reading*
is not: twelve of Module 1's seventeen terms are examinable here against five there, and a
point inside the production possibilities curve is *underutilized resources* in this course
where it is *unemployment* in the other. The two editions are maintained separately for
that reason. The companion site is
**[AP Macroeconomics](https://sevketgunduz.github.io/ap-macroeconomics/)**.
